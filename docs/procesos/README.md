# Guías de procesos de SIPAD

Guías paso a paso para el personal administrativo que opera SIPAD. Cada guía usa los nombres exactos de los menús y botones del sistema, y explica qué bloquea una acción y qué hacer en ese caso.

## ¿Qué querés hacer?

| Tarea | Guía | Menú |
|-------|------|------|
| Cargar, corregir, finalizar o importar designaciones | [Designaciones](designaciones.md) | Docentes y académico → **Designaciones** |
| Cambiar el docente de una materia o un bloque | [Cambio de docente](cambio-de-docente.md) | Docentes y académico → **Gestión académica** / **Planificador de horarios** |
| Armar, revisar y publicar el horario semanal | [Planificador de horarios](planificador-de-horarios.md) | Docentes y académico → **Planificador de horarios** |
| Emitir contratos, recuperar PDFs y revisar sus versiones | [Contratos](contratos.md) | Docentes y académico → **Contratos** |
| Cerrar el mes: biométrico, asistencia, planilla, aprobación y publicación | [Cierre mensual](cierre-mensual.md) | **Cierre mensual** |
| Malla, estudiantes, rematrícula, cursos intensivos, grupos y documentos migratorios | [Gestión estudiantil](gestion-estudiantil.md) | **Gestión estudiantil** |
| Dar de alta docentes, crear usuarios y entregar credenciales | [Docentes y usuarios](docentes-y-usuarios.md) | Docentes y académico → **Docentes** · Administración → **Usuarios** |

## Orden de un semestre típico

1. **Antes de clases:** docentes y usuarios → designaciones (o borrador del planificador) → publicar el horario → emitir contratos.
2. **Cada mes:** cierre mensual. El **Dashboard** muestra en qué paso estás con el stepper **Cierre mensual**.
3. **Durante el semestre:** cambios de docente, finalizar designaciones, nuevas versiones de contrato.
4. **Fin de semestre:** rematrícula del período siguiente, apertura de grupos y cursos de verano o invierno.
